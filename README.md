## Project Overview

The CIT300 Student Campus System is a Java-based data structures project for managing student records and campus route information.

## Data Structures Implemented

### Linked List
- Add student
- Search student
- Update student
- Delete student
- Prevent duplicate student IDs

### Stack
- Push
- Pop
- Peek
- Check size
- Check whether the stack is empty

### Queue
- Enqueue
- Dequeue
- Peek
- Check size
- Check whether the queue is empty

### Binary Search Tree (BST)
- Insert student
- Search student by ID
- In-order traversal

### Hash Table
- Insert student
- Search student by ID

### Graph
- Add campus locations
- Add campus connections
- Remove connections
- Remove locations
- Breadth-First Search (BFS)
- Depth-First Search (DFS)

## Testing

The implemented data structures were tested using Java test classes.

Tested components:
- BST and Hashing
- Linked List
- Stack and Queue
- Graph, BFS and DFS

All implemented test cases were successfully executed.
